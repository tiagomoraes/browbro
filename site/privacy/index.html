Privacy Policy

Last updated 2 November 2026

BrowBro is a macOS menu-bar app that intercepts clicked web links on your Mac and lets you pick which browser or Chrome profile opens them. It is made by Tiago Moraes. This policy covers the app and this website.

What BrowBro does on your Mac

When you make BrowBro your default browser, macOS delivers the clicked URL to BrowBro. BrowBro shows a picker and then opens that URL in the browser you choose. Routing happens entirely on your computer. BrowBro does not load the page, does not run a web view, and does not send the URL to us.

What we collect

Nothing. There is no BrowBro account, no analytics, no crash reporter, no advertising identifier, and no server that receives your links or browser list.

What stays on your Mac

  • Preferences — default-browser status, picker order, visibility, and behavior toggles. Stored in macOS UserDefaults on this Mac. The Mac App Store build keeps them inside its sandbox container.
  • Recent links — a short in-memory / local list so you can re-route a link you just opened. It never leaves the device.
  • Chrome profiles — if you grant access, BrowBro reads Google Chrome’s local Local State file to list profile names, optional email labels, and colors. That file is Chrome’s, on your disk. BrowBro does not upload it. Access is limited to the folder you pick in the open panel (or, outside the Mac App Store, the equivalent TCC grant). You can decline; the rest of the app still works, without per-profile targets.
  • Login item — only if you turn on “Launch at login” in Settings.

Network

BrowBro itself does not need the network to route a link, and the links you click never leave your Mac. Opening the GitHub repo or this site from Settings uses your default browser (which, while BrowBro is the default handler, is BrowBro — the picker will ask where to open it).

The direct download (DMG / Homebrew) build makes one kind of request of its own: it checks for updates via Sparkle by fetching browbro.tiagomoraes.cloud/appcast.xml. Automatic checks are on by default (about once a day) and can be turned off in Settings → Updates. Check for Updates… checks on demand. The request carries what any download does — your IP address and the app’s version in its user agent — and never your links, browser list, or Chrome profiles. Sparkle’s optional system profile is off. An update itself downloads from GitHub Releases and is verified against an EdDSA signature before it installs.

The Mac App Store build does not include Sparkle, makes no network requests, and is updated by Apple.

This website

This site is a static page hosted on GitHub Pages. GitHub serves it and, like any web host, logs visitors’ IP addresses, under GitHub’s privacy statement. The update feed above is served the same way.

  • No cookies, analytics, or trackers — the site sets no cookies and loads no analytics, advertising, or tracking scripts.
  • Fonts — Plus Jakarta Sans and JetBrains Mono are served from this site, not from a font service.
  • GitHub star count — the home page asks GitHub’s public API (api.github.com) for the repository’s star count. Your browser sends that request straight to GitHub, so GitHub sees your IP address, under the same privacy statement. The answer is cached for an hour, so reloading doesn’t ask again.
  • Local storage — two keys in your browser’s localStorage, read only by this site and never sent anywhere: bb-theme (light or dark, saved only once you use the theme toggle) and bb-gh-stars (the last star count and when it was fetched). Clearing this site’s data in your browser removes them.

Children

BrowBro is a utility. It does not target children and does not collect personal information from anyone.

Changes

If this policy changes, the date at the top of this page will change. Continued use of BrowBro after an update means you accept the new policy.
